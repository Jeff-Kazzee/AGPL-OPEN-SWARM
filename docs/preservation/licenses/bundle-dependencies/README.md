# Dependency notices for the YouTube, Reddit and Microsoft 365 bundles

The archive's generated JavaScript names 178 packages across these three bundles. The links below open the licence files for the releases checked. The [inventory](inventory.json) records the bundle, version evidence, npm archive integrity and SHA-256 of each notice. A version embedded in the JavaScript is direct evidence. A version in a tool author's lockfile or available from npm when OpenSwarm committed the bundle is a candidate. A matching filename or line of code alone cannot identify the release. The [Microsoft 365 source comparison](../softeria-verification/README.md) and [Google client comparison](../google-youtube-api/README.md) give more detail. The [Notion server](../notion-internals/README.md) has its own inventory.

The releases of youtube-transcript-plus [2.0.0](https://github.com/ericmmartin/youtube-transcript-plus/tree/cbe1f40fc923a1896df883493045170cfd644dd5) and [2.0.1](https://github.com/ericmmartin/youtube-transcript-plus/tree/4e54f971727e665bb9e6995086dda620f0596871) declare MIT and link to a missing licence file. The maintainer subsequently supplied the full text crediting both Sylvestre Bouchot and Eric Martin and documented that the earlier npm release omitted it. Both rows link to that [later upstream notice](https://github.com/ericmmartin/youtube-transcript-plus/commit/5b2f3ca3512faa6e80f027ecd7e0593c7cf1a1b9). For data-uri-to-buffer 4.0.1, the full notice was in the published README.
