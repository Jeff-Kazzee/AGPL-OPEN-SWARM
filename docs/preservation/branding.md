# Proposed archive identity

**Swarm Cabinet** is the proposed name for the preservation repository. The name describes a place to keep a specific snapshot. The tagline identifies the source and version as an independent community preservation copy of OpenSwarm 1.7.7.

The [original archive mark](swarm-cabinet.svg) uses three turquoise file tabs behind a cabinet label. The mark is drawn from geometric shapes. It uses no upstream artwork, product marks, fonts, or third-party images. Its narrow shape and limited colours keep it recognisable at repository icon size.

Use the name and mark on the archive README and repository description. Preserve OpenSwarm's original authorship and assets in the source import. A future application rename needs its own review of package identifiers, update destinations, user data directories, signing, and services.
