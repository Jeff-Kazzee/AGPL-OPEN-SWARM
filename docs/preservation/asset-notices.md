# Asset provenance and redistribution review

The archived recordings, shader code and copied skill descriptions have separate redistribution considerations. The archive establishes where these files came from. It does not establish permission from everyone whose work or account information appears in them. This review covers the source snapshot. A signed installer, hosted service, or generated app has a different set of contents.

Checked on 2026-11-17 against OpenSwarm commit `14120a43f7e43cbe5a1263fe379b8dfe0a195fb0`. The Git blob IDs matched the pinned upstream tree for all 19 PNGs, five SVGs, three ICO or ICNS files, six MP4s, the provisioning profile, and seven selected source or notice files. The later Swarm Cabinet mark has its own [design record](branding.md). ## Apple signing profile

The [Electron package](../../electron/package.json#L69) selects [embedded.provisionprofile](../../electron/build/embedded.provisionprofile) for macOS. Its signed container has one signer and three certificates with no private keys. The signature verified mathematically using .NET `SignedCms.CheckSignature(true)`. This check skips certificate-chain trust. The XML profile includes one developer certificate, team and app identifiers, a keychain access group, and an all-devices flag. No individual device list appears. The profile records creation on 2026-06-28 and expiry on 2044-06-23. Those dates do not establish current signing authority.

The profile identifies upstream's signing team. Use the downstream publisher's own signing identity and any required profile for a downstream release. No evidence in the source grants permission to republish the original as a standalone developer credential. Confirm any separate basis before including it in an unrestricted mirror. [Apple's profile format](https://developer.apple.com/documentation/technotes/tn3125-inside-code-signing-provisioning-profiles) · [Apple Developer Program agreement](https://developer.apple.com/support/terms/apple-developer-program-license-agreement/)
